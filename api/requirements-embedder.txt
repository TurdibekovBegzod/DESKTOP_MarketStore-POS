# Only the embedder image installs these. Kept out of requirements.txt because
# torch is a few hundred megabytes and neither the api nor the Celery worker ever
# loads a model - adding it there would slow every deploy and every cold start
# for code that is not used.
#
# The CPU wheel index is not optional: the default PyPI torch carries bundled
# CUDA libraries that run to gigabytes and are dead weight on a server with no
# GPU.
--extra-index-url https://download.pytorch.org/whl/cpu
