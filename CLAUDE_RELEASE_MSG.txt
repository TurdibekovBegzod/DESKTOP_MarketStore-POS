release: v1.6.2 yangilanishni yuklab olishdagi 404 tuzatildi

Dastur yangi versiyani topardi, lekin yuklab olishda "HTTP Error 404"
berardi - garchi reliz joyida turgan bo'lsa ham.

Nima bo'lgan

- Server yangilanish faylini GitHub'ning asset API'si orqali uzatadi. U
  tokensiz soatiga 60 ta so'rovga cheklangan, barcha mijozlar esa bitta
  server manzilidan keladi - shuning uchun chegara tez tugaydi.
- Chegara tugagach GitHub so'rovni rad etadi, server esa buni xatoga
  aylantirib dasturga qaytaradi.
- Reliz ommaviy, ya'ni faylning o'zi GitHub havolasidan bemalol
  yuklanardi. Shunchaki hech kim u yerga murojaat qilmasdi.

Nima o'zgardi

- Dastur endi server javobidagi to'g'ridan-to'g'ri havolani zaxira
  sifatida ishlatadi. Serverdan yuklab bo'lmasa, fayl GitHub'dan olinadi.
  Oraliq xato ko'rsatilmaydi - foydalanuvchi faqat ikkala yo'l ham
  yiqilganda xabar oladi.
- Server ham o'z tomonidan tuzatildi: fayl uzatib bo'lmasa, dasturni
  to'g'ri havolaga yo'naltiradi. Havola saqlangan relizdan o'qiladi, ya'ni
  GitHub bizni rad etayotgan paytda unga yana murojaat qilinmaydi.
- Bekor qilingan yuklash endi xato deb hisoblanmaydi, chunki u
  foydalanuvchining o'z qarori.

Tekshirildi: v1.6.1 relizi to'liq yuklab olindi (30.1 MB), fayl hajmi va
SHA-256 tekshiruvidan o'tdi. API testlari 189 passed, desktop 245 passed.
